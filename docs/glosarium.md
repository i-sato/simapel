# Glosarium

Istilah yang dipakai di aplikasi dan dokumentasi SIMAPEL.

| Istilah | Arti |
|---|---|
| Administrasi siap | Tenggat (H+n setelah pendaftaran ditutup) saat BAP, SK, dan ST seharusnya sudah lengkap. Setelah tenggat ini, dokumen yang belum selesai berstatus "kritis" |
| Admin (pelatihan) | Pegawai bertanda "dapat menjadi Admin" yang ditugaskan pada pelatihan tertentu; melengkapi dan memfinalisasi pelatihan tersebut |
| BAP | Berita Acara penetapan peserta |
| Bentrok | Dua tugas seorang pegawai pada pelatihan berbeda yang rentang waktunya beririsan (awal pendaftaran sampai akhir pelatihan) |
| Beban kerja | Jumlah pelatihan yang ditangani seorang pegawai per minggu/bulan |
| CoC | Certificate of Completion (sertifikat penyelesaian) |
| Delegasi | Penunjukan Sekretaris tim sebagai penanggung jawab dokumen BAP/SK/ST |
| Digitalent / DTS | Platform pelatihan pusat Komdigi (Digital Talent Scholarship) tempat peserta mendaftar |
| Draft / Final | Status administrasi pelatihan. Draft boleh belum lengkap; Final sudah lengkap dan menyimpan salinan ketentuan SOP |
| DTA, KDD, ASN | Tim kerja Talenta Digital, Keterampilan Digital Dasar, dan ASN Digital |
| Fallback (ketentuan) | Pemakaian ketentuan SOP tahun sebelumnya bila tahun berjalan belum memiliki ketentuan Berlaku |
| H+n | n hari setelah tanggal akhir pendaftaran (H+0 = hari terakhir pendaftaran) |
| JP | Jam pelajaran |
| JRA | Jadwal Retensi Arsip: aturan berapa lama data/arsip disimpan |
| Ketentuan SOP | Acuan SOP (nomor, tanggal, link) dan tenggat BAP/SK/ST/administrasi siap per tim per tahun anggaran; berstatus Draf, Berlaku, atau Diganti |
| Learning path | Rangkaian pelatihan berjenjang: Level 1 Dasar, Level 2 Menengah, Level 3 Mahir |
| Mitra | Organisasi pelaksana pelatihan beserta wilayah kerjanya |
| NIP | Nomor Induk Pegawai (18 digit); ditampilkan tersamar |
| Panitia | Pegawai yang ditugaskan membagikan informasi pelatihan ke peserta (kepesertaan) |
| PDP / UU PDP | Pelindungan Data Pribadi (UU No. 27 Tahun 2022) |
| Placeholder | Penanda seperti `{{nama_pelatihan}}` di template WA yang diganti dengan data pelatihan |
| PPDP | Pejabat/Petugas Pelindungan Data Pribadi |
| SK | Surat Keputusan peserta |
| ST | Surat Tugas |
| Status waktu | Akan dibuka, Pendaftaran, Penetapan peserta, Pelaksanaan, Selesai; dihitung otomatis dari tanggal |
| Super Admin | Pengelola sistem dengan akses ke seluruh fitur |
| UAT | User Acceptance Test (uji penerimaan pengguna) |
| WIB / WITA | Waktu Indonesia Barat (DIY, Jawa Tengah) / Waktu Indonesia Tengah (Bali), WIB + 1 jam |
| Wilayah kerja | DIY, Jawa Tengah, atau Bali; menentukan zona waktu di template WA |
