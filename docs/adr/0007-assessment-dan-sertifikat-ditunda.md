# ADR 0007 — Assessment dan sertifikat ditunda

- Status: Diterima (4 November 2026)

## Konteks

Referensi memiliki bank soal pilihan ganda, input jawaban oleh admin, penilaian otomatis, dan sertifikat regional. TOR menempatkan assessment dan sertifikat di luar MVP kecuali disetujui. SOP menetapkan kelulusan dari penilaian pengajar dan data LMS. Proses bisnis assessment dan sertifikat belum ada.

## Keputusan

Modul assessment dan sertifikat **tidak** dibawa ke refactor sampai proses bisnisnya ditetapkan pemilik proses (keputusan pemilik proyek, 4 November 2026).

## Konsekuensi

- Status kelulusan peserta kelak mengikuti status SOP/DTS (Lulus/Tidak lulus/Tidak hadir), bukan hasil skor internal.
- Bila nanti diaktifkan, keputusan otomatis perlu penilaian dampak dan mekanisme keberatan sesuai UU PDP Pasal 10 (lihat docs/kepatuhan-pdp.md).
